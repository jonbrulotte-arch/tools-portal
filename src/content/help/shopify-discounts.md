The Shopify Discount Code Generator creates discount codes on our Shopify stores without logging in to Shopify admin. This SOP is for Customer Service and anyone else who creates codes.

## The discount log

**Discount log** lists the discounts created with this tool: the title, code(s), value, store, who created it, when, and whether it succeeded.

![The discount log](images/discount-log.jpg)

A **Failed** entry shows Shopify's reason, for example *Code … is already in use on this store*. Nothing was created on that store, so fix the problem and create it again.

Unless your role allows you to view all discounts, you see the ones you created.

## Creating a discount

Click **New discount** and work down the numbered sections. The **Summary** on the right shows what will be created.

![New discount: store, code and value](images/new-discount.jpg)

1. **Store**: tick the store(s). Selecting several creates the same discount on each.
2. **Discount code**:
   - **Internal title**: for us (shown in Shopify admin and in the log), for example *Customer goodwill: order 1234*.
   - **Single code**: one code many customers can use. Type it, or click **Generate** for a random one.
   - **Generate unique codes**: many random codes, for example one per customer.
3. **Value**: **Percentage**, **Fixed amount** or **Free shipping**, and what it **applies to**: all products, or specific collections or products (pick one store for these).
4. **Requirements & limits**: a minimum purchase amount or quantity, a total number of uses, and one use per customer.
5. **Combinations**: whether it can be combined with product, order or shipping discounts.
6. **Active dates**: when it starts, and optionally when it ends.

![Requirements, limits, combinations and dates](images/new-discount-limits.jpg)

Click **Create discount**. Copy the code(s) from the result and send them to the customer.

> Note: Some fields may be **locked** (greyed out) by the tool's managers, for example *one use per customer*. That's company policy for everyone; ask a manager if a case needs an exception.

## Good practice

- Use a clear internal title that says why the code exists (order number, campaign or case).
- For one customer, use a single code with **1 total use** and **one use per customer**, and set an end date.
- Never share a code meant for one customer publicly.
- To change or delete a discount after it's created, use Shopify admin, or ask a manager.
