For admins with the **Manage tools** permission. **Admin → Tools** lists every tool on the platform.

![Tools](images/tools.jpg)

| Column | Meaning |
| --- | --- |
| Tool | Name and icon, as shown in the sidebar and on the dashboard |
| Description | The one-line description under the tool's title |
| Status | **Enabled** or **Disabled** |
| Granted to | How many roles give access to it |

## Editing a tool

Click **Edit tool** to change the **Name**, **Description**, *What it's used for*, **Icon** and **Order** (its position in the sidebar and on the dashboard).

## Turning a tool off

Turn the **Enabled** switch off in the edit dialog to hide a tool from **everyone**, Super Admins included, without changing any role. Use it for maintenance, or before a tool is ready. Its data and settings are kept, and turning it back on restores access as before. Its Help & Docs guides are hidden too.

> Note: Turning a tool off hides it from people; it doesn't stop its background jobs. To stop Automated Emails from sending, turn off **Send automatically** in that tool's Settings.

Access to a tool is granted in **Admin → Roles** (or per user), not here.
